아는 것만 적으면 AI가 물어보고, 기획서가 첫 게임이 됩니다.

REVIEW

4호 숙제,
해 봤나요?

4호 마지막에 이렇게 말했어요. 게임 기획은 이 네 가지만 적어도 시작할 수 있다고요.

1

장르 어떤 게임인가요?

2

디자인 어떤 모습, 어떤 분위기인가요?

3

조작 어떻게 움직이고 어떤 키를 쓰나요?

4

규칙 목표는? 점수는? 어떻게 지거나 이기나요?

그런데 막상 쓰려고 하면 이런 생각이 들죠.

장르에 뭐가 있는지도 잘 모르겠어요.

조작이랑 규칙은 어떻게 정하는 건지 감이 안 와요.

안 써 봤어도, 못 썼어도 괜찮아요. 그게 보통입니다. 지금부터 같이 생각해 봐요.

IDEA

처음엔 다
막연해요

게임을 만들고 싶은 친구는 대개 둘 중 하나예요.

"뭘 만들지 아직 생각을 못 했어요."

"고양이가 나오는 게임이면 좋겠는데… 그것 말고는 모르겠어요."

그래도 시작할 수 있어요. 전부 정하고 시작할 필요가 없거든요. 내가 아는 만큼만 정하고, 모르는 부분은 AI에게 질문을 맡기면 됩니다.

답하는 요령

  • 고르기만 해도 돼요. 선택지 중에 마음에 드는 걸 말하면 됩니다
  • 모르겠으면 추천을 받아요. "네가 추천하는 걸로 갈게"라고 해도 좋아요
  • 마음에 안 들면 바로 말해요. "이건 싫어, 이렇게 바꿔 줘"
  • "고양이"처럼 꼭 넣고 싶은 건 끝까지 지켜요. 그게 내 게임의 핵심이에요

질문과 대답이 끝났다면 이제 AI에게 방금까지 정한 내용을 문서로 모아 달라고 하면 돼요.

고양이의 비밀 방웹 브라우저 방탈출 게임 · 기획서 v1.0

기획 기준: 사용자와의 단계별 문답에서 확정한 내용

1. 게임 개요

고양이가 있는 작은 비밀의 방에서 마우스로 사물을 조사하고, 단서와 아이템을 모아 퍼즐을 해결한 뒤 숨겨진 열쇠로 방문을 열어 탈출하는 2D 포인트 앤 클릭 게임.

항목 확정 내용
장르 방탈출 / 퍼즐 / 탐색
플랫폼 PC 웹 브라우저에서 바로 실행
플레이 인원 1명
배경·소재 고양이의 비밀 방
그림 스타일 귀여운 손그림 느낌
필수 등장 요소 고양이
조작 마우스로 물건을 클릭해 조사하고 상호작용
난이도 보통
예상 규모 방 1개, 퍼즐 3~4개, 짧은 1회 플레이(약 5~10분 목표)

2. 승리·패배 및 평가 규칙

  • 승리(클리어): 퍼즐을 풀어 숨겨진 열쇠를 획득하고, 해당 열쇠로 방문을 열면 탈출 성공.
  • 패배 조건: 없음. 제한 시간과 실수 횟수 제한을 두지 않음.
  • 점수·등급·순위: 없음. 클리어 여부만 존재하며 성공 시 탈출 성공 화면을 표시.
  • 진행 저장: 없음. 브라우저를 새로고침하거나 닫았다 다시 열면 처음부터 시작.

3. 게임 화면 및 조작

  • 메인 화면: 방 전체를 하나의 화면에서 볼 수 있도록 구성. 다른 방으로 이동하거나 시점을 전환하지 않음.
  • 조사: 사물을 클릭하면 해당 물건의 세부 모습 또는 퍼즐 화면을 보여줌.
  • 아이템 보관함: 화면 아래에 배치. 발견한 아이템은 보관함에 추가됨.
  • 아이템 사용: 보관함에서 아이템을 클릭해 선택한 뒤, 방 안의 사용 대상을 클릭함.
  • 확대 화면 종료: 닫기 조작으로 다시 전체 방 화면으로 돌아감.

4. 퍼즐 구성과 진행 구조

  • 퍼즐의 기본 형태: 암호·숫자·그림 단서 추리와 아이템 수집·사용을 섞음.
  • 처음에는 여러 사물과 단서를 자유롭게 탐색하거나 일부 퍼즐을 독립적으로 해결할 수 있음.
  • 마지막 퍼즐은 앞서 모은 단서 또는 아이템을 연결해야 풀 수 있도록 구성.
  • 목표 퍼즐 수는 총 3~4개. 최종 보상은 방문을 여는 열쇠.

5. 고양이의 역할과 힌트

  • 고양이는 배경 장식이 아니라 퍼즐 해결에 직접 관여하는 핵심 캐릭터.
  • 간식이나 장난감 등 특정 아이템을 사용하면 고양이가 반응하고, 위치를 바꾸거나 숨겨진 단서가 나타날 수 있음.
  • 고양이가 힌트를 제공하되, 정답을 글이나 문장으로 설명하지 않음.
  • 시선, 몸짓, 앞발, 이동, 특정 사물을 바라보는 행동 또는 그림으로만 힌트를 전달.

6. 연출 및 소리

  • 기본 기능에 고양이의 간단한 움직임, 물건을 클릭할 때의 시각 효과, 효과음을 더함.
  • 복잡한 애니메이션보다는 표정 변화·자리 이동·짧은 반응 중심으로 구성.

7. 첫 번째 버전 구현 범위

포함 이번 버전에서 하지 않을 것
방 1개, 사물 클릭 및 확대 조사 다수의 방과 스테이지
퍼즐 3~4개, 암호 추리와 아이템 사용 복잡한 대규모 퍼즐 시스템
하단 아이템 보관함 온라인 로그인·회원가입
그림·행동으로 힌트를 주는 고양이 텍스트로 정답을 알려주는 고양이 힌트
간단한 움직임·클릭 효과·효과음 복잡한 애니메이션·배경음악·설정 메뉴
클리어 화면 점수·순위·패배·시간제한·저장·이어하기

8. 구현 방식 및 개발 유의사항

  • HTML: 방 화면, 확대 조사 창, 퍼즐 창, 보관함 등 화면 구성.
  • CSS: 귀여운 손그림 분위기의 색상·레이아웃·짧은 전환 효과.
  • JavaScript: 클릭 처리, 아이템 획득·선택·사용, 퍼즐 상태와 클리어 판정.
  • 서버와 데이터베이스 없이 로컬 브라우저에서 실행 가능한 정적 웹게임으로 제작.
  • 이미지·효과음은 외부 파일로 나누어 관리할 수 있음. HTML 파일 하나로 묶을지는 구현 시 결정.

9. 세부 퍼즐 예시 (확정 사항 아님)

아래는 앞서 제시된 구체화 예시로, 퍼즐의 정답·단서 배치·보상과 아이템 명칭은 아직 최종 확정되지 않았습니다.

예시 퍼즐 탐색 또는 해결 방식 예시 보상
발자국 암호 발자국 그림의 숫자와 순서를 조사해 서랍 암호 입력 고양이 간식
고양이의 비밀 간식을 고양이에게 사용해 자리 이동 유도 그림 조각
그림의 순서 액자와 조각을 비교해 그림의 순서 추리 별 모양 장식
마지막 상자 수집한 단서 및 장식을 사용해 비밀 상자 열기 방문 열쇠

10. 개발 착수 전 확인할 세부 사항

기획의 방향은 확정되었으며, 아래의 세부 항목은 제작용 상세 설계 단계에서 결정합니다.

  • 방 안에 놓일 사물의 정확한 목록과 위치
  • 각 퍼즐의 실제 정답, 오답 처리 및 단서가 보이는 조건
  • 고양이의 동작별 등장 시점과 힌트 제공 조건
  • 클릭 가능 영역과 아이템 선택·해제 표시 방식
  • 최종 그래픽·효과음 파일 목록과 화면 크기
⬇ 기획서 파일(Word) 내려받기

9번 "세부 퍼즐 예시"에는 확정 사항 아님이라고 적혀 있어요. AI가 정해진 것과 아직 안 정해진 것을 나눠 적어 줬습니다.

REVISE

기획서는
고치면서 완성해요

AI가 정리해 준 기획서도 처음에는 초안(v1)입니다. 만들기 전에 한 번 점검하고, 고칠 곳은 기획서부터 고칩니다.

1

점검 AI에게 허점을 물어봅니다

2

답하기 질문에 하나씩 대답합니다

3

반영 대답을 넣어 기획서를 고쳐 달라고 합니다

① 점검 요청문

위 기획서대로 게임을 만들려고 해. 만들기 전에, 모호하거나 빠졌거나 서로 안 맞는 부분을 질문으로 알려 줘. 아직 코드는 만들지 마.

② 반영 요청문

방금 내가 대답한 내용을 반영해서 기획서를 고쳐 줘. 바뀐 부분에는 (수정) 표시를 해 주고, 기획서 이름은 v2로 해 줘.

이렇게 바뀌어요 (예시)

v1퍼즐: 3~4개9번 퍼즐 예시는 확정 사항 아님
v2퍼즐: 4개로 확정 (수정)발자국 암호, 고양이의 비밀, 그림의 순서, 마지막 상자

고칠 때 지킬 세 가지

  • 한 번에 하나씩. 여러 개를 한꺼번에 바꾸면 뭐가 어떻게 달라졌는지 알 수 없어요
  • 바뀐 곳을 표시하게 해요. (수정) 표시가 있으면 내가 확인하기 쉬워요
  • 최신 기획서는 한 벌만. v1, v2처럼 이름을 붙이고 가장 최신 것만 AI에게 붙여넣어요
BUILD

이제,
첫 게임을 만들어요

기획서가 있으니 제작 요청은 한 번이면 돼요. 최신 기획서를 붙여넣은 뒤 이렇게 말합니다.

제작 요청문

위 기획서대로 HTML 파일 하나로 실행되는 게임을 만들어 줘. 가장 작은 버전부터 만들고, 기획서에 없는 기능은 넣지 마. 다 만든 뒤에 기획서와 다르게 만든 부분이 있으면 알려 줘.

1

파일을 저장하고 더블클릭해서 엽니다 (방법은 4호와 같아요)

2

직접 해 보고, 기획서와 같은지 비교합니다

3

다르거나 아쉬운 곳은 기획서를 고쳐서 다시 요청해도 돼요

기획서로 만든 첫 게임 「고양이의 비밀 방」. 방 하나, 아래에 아이템 보관함, 가운데에는 고양이가 있어요.

"기획서에 없는 기능은 넣지 마"는 4호에서 본 AI의 멋대로 더하기를 막아 줘요. 기획서의 "안 할 것"이 여기서 힘을 씁니다.
