바이브 코딩 입문

코딩을 몰라도, 만들고 싶은 게임을 말로 설명하면 AI가 만들어 줍니다.
3호에서 배운 '좋은 요청'이 이번에는 게임이 됩니다.

DEFINE

바이브 코딩이
뭔가요?

바이브 코딩이란 코드를 직접 쓰지 않고, 원하는 것을 말로 설명하며 AI와 함께 프로그램을 만드는 방식입니다.

'바이브(vibe)'는 '느낌, 분위기'라는 뜻이에요. 2025년 2월 AI 연구자 안드레이 카파시가 이 말을 처음 썼고, 그해 영국 콜린스 사전의 올해의 단어로 뽑혔습니다.

GAME

게임으로 보면
더 쉬워요

그럼 바이브 코딩으로 무엇을 만들어 볼까요? 이번 호에서는 게임으로 시작합니다. 게임 하나를 만들려면 원래 세 가지 일이 필요합니다.

디자인

AI가 디자인과 프로그래밍을 맡아 주면서, 가장 중요한 일은 기획이 되었습니다. 어떤 게임을 만들지 정하는 사람이 곧 게임을 만드는 사람입니다.

다만 결과를 직접 해 보고 "여기를 고쳐 줘"라고 말하는 것도 기획자의 일이에요.

TRY IT 1

먼저, 아주 짧게
요청해 볼까요?

요청문

게임 만들어 줘.

ChatGPT에 이 한 줄만 보내 봤습니다. 1분쯤 지나 게임 파일이 만들어졌어요.

요청은 한 줄. 결과는 우주선 게임 「별빛 회피 작전」.
만들어진 게임. 키보드로 운석을 피하고 별을 모아요.

AI가 알아서 정한 것

  • 장르: 떨어지는 운석 피하기
  • 소재: 우주선, 운석, 노란 별
  • 조작: ← → 또는 A D
  • 점수: 피하면 1점, 별을 먹으면 10점
  • 난이도: 시간이 지날수록 운석이 빨라짐

내가 말한 건 "게임 만들어 줘" 하나뿐인데, 나머지는 전부 AI의 취향으로 채워졌습니다. 기획이 비어 있으면 AI가 대신 정해 버립니다.

2

저장한 파일을 더블클릭하면 브라우저에서 열립니다

3

키보드로 게임을 즐겨 보세요

ChatGPT 화면 기준: 2026년 10월. 링크가 보이지 않으면 AI에게 "코드를 보여줘"라고 한 뒤 메모장에 붙여넣어 game.html로 저장해도 됩니다. 무료로 쓸 수 있는 횟수는 정해져 있으니 아껴서 써 보세요.

TRY IT 2

이번엔, 기획을
말해 봤어요

이번에는 만들고 싶은 게임을 장르·디자인·조작·상세로 나눠 설명했습니다.

요청문

내가 설명하는 게임을 만들어 줘.
- 장르 : 횡스크롤 플랫포머
- 디자인 : 2D 픽셀그래픽, 배경은 숲 속
- 조작 : 좌우이동 AD 또는 방향키, 스페이스바로 점프, 나가는 문과 상호작용 (W 또는 위쪽 방향키)
- 상세 : 주인공은 파란 멜빵바지를 입은 꼬마아이, 맵마다 반드시 먹어야 할 아이템(사과), 점수 상승을 위한 아이템(동전), 닿으면 생명력이 감소하는 적이 존재한다. 총 3개의 레벨로 구성, 점점 난이도가 상승한다. 모든 레벨의 클리어 조건은 사과를 전부 먹고 지정된 문으로 나가는 것.
- 게임을 전부 클리어하면 축하합니다! 라는 메시지와 함께 집으로 돌아간 소년이 사과를 맛있게 먹는 그림이 나온다.

같은 ChatGPT, 같은 사람. 달라진 건 요청뿐입니다.
만들어진 게임 「사과 숲의 작은 모험」. 파란 멜빵바지 소년이 사과를 모아요.
"게임 만들어 줘"→ 별빛 회피 작전 (AI의 취향)AI가 일한 시간 1분 4초
기획해서 요청→ 사과 숲의 작은 모험 (내 게임)AI가 일한 시간 3분 9초

설명한 만큼 AI가 오래 일했고, 결과는 내가 상상한 게임에 가까워졌습니다. 3호에서 배운 "좋은 요청"의 힘이 게임에서도 그대로 통합니다.

FIX

마음에 안 드는 곳은
말로 고칩니다

만들어진 게임을 해 보니 고치고 싶은 곳이 생겼습니다. 그것도 그대로 말했어요.

수정 요청 5가지를 한 번에 말했고, AI가 기존 게임에 적용했습니다.

이렇게 바뀌었어요

  • 플랫폼 아래에 떠 있던 픽셀이 사라졌어요
  • 오래 달리면 조금씩 빨라져요 (최고 속도는 정해 둠)
  • 점프 키를 길게 누를수록 높이 뛰어요 (최고 높이는 정해 둠)
  • 점프할 때 소년의 발 모양이 바뀌어요
  • 밟힌 적이 뒤집힌 붉은 모습으로 잠깐 남았다 사라져요

1번을 확대해서 비교해 볼까요?

수정 후깔끔하게 사라짐

수정 요청, 이렇게 해 보세요

  • 하나씩 구체적으로. 어디가 어떻게 마음에 안 드는지 말해요
  • 선을 정해 주세요. "하지만 최대 속도에 리미트를 걸어 줘"처럼 지나치지 않게 한계를 말하면 좋아요
  • 그대로 둘 것도 말해요. "나머지는 그대로 둬"라고 하면 잘 되던 부분이 바뀌는 일을 막을 수 있어요
INSIDE

게임 파일 속을
들여다볼까요?

방금 받은 파일 하나에는 세 가지 언어가 들어 있습니다. 「사과 숲의 작은 모험」 파일에서 한 줄씩 가져와 봤어요.

HTML뼈대와 내용
<canvas id="game" width="960" height="540">

게임이 그려질 그림판(캔버스)을 화면에 놓는다.

CSS겉모습
canvas{image-rendering:pixelated}

그림을 크게 늘려도 도트가 뭉개지지 않게 해라.

JavaScript동작
function damage(){ … lives--; … }

적에 닿으면 체력(lives)을 1 줄여라.

이 셋을 묶어 프론트엔드(화면 쪽)라고 부릅니다. 브라우저가 이 코드를 읽어서 우리가 보는 게임 화면을 그립니다.

내가 한 말이 코드가 된 곳

기획"닿으면 생명력이 감소하는 적"
lives--
적에 닿는 순간 체력이 1 줄어드는 한 줄이 되었어요.
기획"사과를 전부 먹고 문으로 나가는 것"
world.apples.filter(a=>!a.taken).length
아직 안 먹은 사과가 몇 개인지 세는 코드예요. 0개일 때만 문이 열립니다.
디자인"사과"
rect(a.x+2,a.y+2+bounce,10,10,'#c73e3e')
사과 하나는 빨간색(#c73e3e) 네모 같은 작은 조각들로 그려져 있어요. bounce는 사과가 위아래로 통통 움직이게 하는 값이에요.

게임 속 그림(디자인)과 규칙(프로그래밍)이 모두 JavaScript 안에 들어 있습니다. 내가 한 말 한 줄 한 줄이 코드로 번역된 거예요.

코드를 읽을 필요는 없어요. 궁금하면 저장한 HTML 파일을 메모장 같은 텍스트 편집기로 열어 보세요.

BACKEND

친구와 점수를
겨루려면?

「별빛 회피 작전」에는 최고 점수를 저장하는 기능이 있습니다. 그런데 이 점수는 지금 쓰는 브라우저 안에만 저장됩니다. 친구 컴퓨터에서 열면 최고 점수는 0점이에요.

점수를 서로 비교하려면 점수를 함께 모아 두는 곳이 필요합니다. 이것이 백엔드(서버 쪽)입니다.

클라이언트요청하는 쪽. 게임을 켜는 내 기기(손님)
서버요청을 받아 응답하는 쪽. 점수·계정을 보관하는 컴퓨터(주방)

온라인 게임에서 보던 "서버 점검 중"의 그 서버입니다. 랭킹, 계정, 같이 하기는 모두 서버가 있어야 가능해요.

이런 게임을 만들고 싶다면 백엔드가 필요해요

랭킹친구와 점수 비교 → 서버 + 데이터베이스(점수를 모아 두는 창고)
계정·저장어느 기기에서든 내 기록 이어서 하기 → 서버 + 데이터베이스
함께 하기실시간으로 같이 하는 게임 → 서버
외부 서비스게임에 AI 대화 기능 넣기 → 서버 + API(서비스 연결 창구)
프론트만으로 충분혼자 즐기는 미니 게임. ChatGPT가 한 번에 만들어 주는 규모의 게임은 대부분 여기에 해당합니다.
SHARE

친구에게 링크로
보내려면?

지금 게임은 내 컴퓨터 안의 파일입니다. 파일을 직접 보낼 수도 있지만, 링크 하나로 열리게 하려면 인터넷에 올려야 합니다.

호스팅파일을 올려 두고 늘 켜 두는 공간(서버)
배포호스팅에 올려서 누구나 열어 볼 수 있게 하는 일
도메인사이트의 이름. 브라우저 주소창에 입력하는 주소
DNS · IP컴퓨터는 이름 대신 숫자 주소(IP)로 찾아가요. DNS는 이름을 숫자로 바꿔 주는 주소록이에요
도메인example.com
▼ DNS가 찾아 줘요
IP203.0.113.10

example.com과 숫자는 설명을 위한 예시예요.

앞으로 AI가 "터미널에 입력하세요", "npm으로 설치하세요", "env 파일에 키를 넣으세요"라고 말할 때가 있어요. 그럴 땐 따라 하기 전에 멈추고 뜻을 AI나 선생님께 먼저 물어보세요. 터미널은 글자로 명령하는 창, npm은 부품 설치 도구, env는 비밀 정보를 적어 두는 파일입니다.
